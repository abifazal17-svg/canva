Download & Ekspor Database

Simpan seluruh data ke perangkat Anda untuk cadangan atau migrasi server

1. Full Backup JSON (.json) — Direkomendasikan

Mencakup seluruh tabel (Users, Designs + Gambar Base64, Shares, Data Form Client, serta File Font Kustom). Sangat mudah di-restore kembali langsung lewat panel Admin di server baru.

2. Ekspor Dump MySQL (.sql) — Untuk phpMyAdmin / MySQL

Menghasilkan skrip SQL lengkap (CREATE TABLE + INSERT INTO) yang siap di-import langsung melalui phpMyAdmin, DBeaver, atau terminal MySQL pada hosting baru.
